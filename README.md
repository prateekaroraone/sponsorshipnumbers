# UK Sponsorship Lookup (minimal)\n\nPut your FOI workbook at `data/sponsorship_data.xlsx`. Expected sheets: `FOI Data - Skilled Worker` and `FOI Data - GBM`. Each needs Organisation Name, 2021, 2022, 2023, 2024, Grand Total.\n\n## Run locally\n```bash\npython -m venv .venv\n# Windows: .venv\\Scripts\\activate\n# macOS/Linux: source .venv/bin/activate\npip install -r requirements.txt\nstreamlit run app.py\n```\n\n## Deploy\nPush to GitHub, then create an app at https://share.streamlit.io/ using this repository and `app.py`.\n\n**Privacy:** Public GitHub repositories expose their workbook to anyone. Only publish data you are comfortable making public.\n
